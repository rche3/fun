# Archived

This project is no longer actively developed. It is kept here for reference.

To run it again:

```bash
npm install
cp .env.example .env   # then fill in the values
npm start
```

The `certs/` directory (Apple Wallet signing certs) and `data/*.db` are not
committed — you'll need to regenerate them. See [README.md](README.md) for the
full setup.
